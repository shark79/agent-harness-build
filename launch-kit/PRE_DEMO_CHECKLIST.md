# Pre-demo checklist

- [ ] Follow [TrueForge setup](../TRUEFORGE_SETUP.md) and run `make trueforge-check`.
- [ ] Dashboard says TrueForge and shows the expected saved agent.
- [ ] Model and actual MCP tools are configured and authenticated.
- [ ] Delivery tool is explicitly approval-gated in TrueForge.
- [ ] Recipient is a controlled test destination; no personal inbox content is visible.
- [ ] Source retrieval is real; delivery receipt/message ID was verified in rehearsal.
- [ ] Denying a request produces no delivery.
- [ ] Refresh and bridge restart preserve the pending session.
- [ ] Optional sandbox/skill/subagent claims are backed by observed native events.
- [ ] Tests pass, README is reproducible, and repo/video/history contain no secrets.
- [ ] Recording is approximately three minutes and shows the approval pause.
