# Three-minute TrueForge demonstration

Preparation: follow [TRUEFORGE_SETUP.md](../TRUEFORGE_SETUP.md), authorize your connectors, choose a recipient you control, and verify a complete run before recording. Hide keys and personal inbox contents.

- **0:00–0:20:** Show the concrete job and the dashboard's TrueForge runtime banner. Explain the intended artifact and delivery.
- **0:20–1:05:** Submit the job with its recipient. Show actual search results and source links. If configured, show subagent threads and report generation in TrueForge's sandbox.
- **1:05–1:45:** Film the approval pause. Show the exact tool name, recipient, and content. Explain that the harness is waiting before delivery.
- **1:45–2:20:** Approve. Show the tool response/message identifier and the received briefing or other externally verified result.
- **2:20–2:45:** Reopen the session/history. Show the persisted trace and any downloadable report.
- **2:45–3:00:** Show the repository README and setup commands. State any remaining limitations honestly.

Record a separate denial run during rehearsal: no delivery must occur. Do not present the offline “Model Failure” or simulated email as TrueForge evidence. If a run takes longer than the recording window, use a clearly labeled edit and preserve the full approval sequence.
