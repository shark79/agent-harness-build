# Campaign Strategy

Use only after `campaign-brief` has returned a validated brief.

Create exactly three creative directions. Each must include:

- a memorable concept name;
- objective and audience insight;
- primary message and CTA;
- visual direction and suggested static-image treatment;
- why the direction suits the requested platforms;
- claims and sources, if any claim came from research.

Make concepts genuinely distinct (for example: product proof, customer transformation, or cultural/aspirational). Do not generate images, final copy, drafts, or publishing payloads yet.

End with a clear human checkpoint: ask the user to select one concept or request specific changes. Continue only after they explicitly approve a single concept.
