# CampaignForge ad-image prompt template

Use this template to write one clear, production-ready prompt before calling `generate_image`.

```text
Campaign goal: [single desired action or perception]
Audience: [specific viewer and relevant context]
Main subject: [product/person/object and what it is doing]
Scene and composition: [setting, camera/framing, focal hierarchy, and reserved negative space]
Visual style: [photography/illustration style, materials, lighting, color palette, and mood]
Brand constraints: [approved visual traits and forbidden claims/logos]
In-image copy: [exact copy, typography, color, and placement] OR "No in-image text; preserve negative space at [location]."
```

Keep the result focused on one visual idea. Describe visible details concretely instead of using vague quality labels. For revisions, specify exactly what changes and what must remain unchanged.
